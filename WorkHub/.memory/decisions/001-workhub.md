# WorkHub 데모 결정 기록

2026-11-07

- 요청: Canvas 앱치고 고급스러운 UI와 목록·상세·로그·대시보드, PCF 기반, 바이브 코딩 사례 시연.
- 사용자 추가 결정: 프로젝트·업무 요청, IT 서비스·장애, 구매·지출 승인을 한 앱에 통합.
- 전달 방식: 파일만 받고 사용자가 회사 환경에 직접 가져오기. 환경에 접속하거나 배포하지 않음.
- 디자인: 네이비 사이드바, 민트 강조, 밝은 표와 카드, 넉넉한 여백, 모바일 축약 메뉴.
- 구성: 전체 화면 PCF 하나가 모든 탐색·모달·상태를 담당. Canvas 호스트는 크기와 입력·출력만 담당.
- 첨부 문서 적용: 공통 부품과 디자인을 재사용하고 결정·검증 기록을 소스에 남김. 문서 속 슬래시 명령은 사용자 실행 지시로 해석하지 않음.
- MCP 실제 호출 없음. AI 응답·전자결재·결제·서버 감사 로그를 실제 기능처럼 표시하지 않음.
- 가져오기: 정식 CLI/MSBuild로 생성한 PCF 솔루션을 전달. Studio 원본이 없는 상태에서 내부 msapp JSON을 조립해 완성 앱이라고 제공하지 않음.
- 데이터: 가상 데이터 24건, 인스턴스별 메모리 저장소, React Query 캐시. 영구 저장은 운영 연동 단계.
- 범위 밖: 운영 인증과 권한, 데이터 커넥터, 다단계 실제 결재, 첨부파일, 푸시 알림, 서버 검증.
